\begin{abstract}
В этой записке фиксируется текущее состояние mixed-weak ветви после
завершенных локальных проверочных пилотов.
Ее назначение --- обсуждение и синхронизация, а не полное выведение.
Основной акцент сделан на принятой рабочей структуре, компактных замкнутых
формулах, уже доступных на уровне репозитория, локально проверенных
компонентах и ключевых открытых пунктах, которые пока не позволяют получить
замкнутую теорему уровня статьи.
\end{abstract}

\section{Введение}
Текущим активным направлением проекта является mixed-weak ветвь.
Она заменила прежнюю reduced/full архитектуру после того, как тот путь не дал
качественно нового и устойчивого основного критерия.
Цель настоящей записки не в том, чтобы заново выводить теорию оболочки с нуля,
а в том, чтобы дать компактное, ориентированное на обсуждение с научным
руководителем резюме той формулировки уровня репозитория, которая сейчас
фактически проверяется и используется.

\section{Постановка задачи}
В настоящее время в проекте рассматривается линеаризованная неосесимметричная
задача в окрестности исправленного осесимметричного докритического фона,
в рамках mixed-weak ветви и ее текущих рабочих граничных условий,
ориентированных на simple support.
Настоящая записка относится только к текущей границе верификации:
\begin{itemize}[leftmargin=2em]
    \item активному классу mixed-weak операторов,
    \item текущей логике сопряженных граничных пар,
    \item текущему построению регулярных в центре мод,
    \item текущей смешанной граничной матрице $B_{\mathrm{mix}}$,
    \item текущему рабочему спектральному индикатору
    $\sigma_{\min}(B_{\mathrm{mix}})$.
\end{itemize}
Это не является окончательной теоремой для полной замкнутой краевой задачи
оболочки и не удостоверяет окончательную физическую критическую нагрузку для
simple-support постановки.

\paragraph{Активный рабочий путь.}
На текущем этапе для этой задачи активен clean путь.
Рассматривается clean path для full \texttt{simple support / подвижный шарнир}
постановки на честном 6-компонентном осесимметрическом фоне
$(T_s,T_{sn},M_s,u_r,u_z,\varphi)$ с условиями
$T_{sn}(x_0)=0$, $u_r(x_0)=0$, $\varphi(x_0)=0$, $T_s(1)=0$, $M_s(1)=0$,
$u_z(1)=0$ и отдельным mixed-weak critical-search слоем с граничными строками
$[u_n(1),\varphi(1),T_s(1),S(1),H(1)]$.
Сохранённые hybrid mixed-weak scans на базе $F_{\min}$ оставлены только как
comparison / diagnostic testbenches и не считаются текущим theorem-facing path
для clean задачи \texttt{simple support / подвижный шарнир}.
Операционный статус clean full-state path вынесен в
\texttt{docs/theory/current_simple_support_status.md}. Текущий theorem-facing pilot 23
доведён сейчас до boundary-scoped Outcome B: на checked local boundary
правильный local selected object замыкается как quotient, а не как canonically normalized 2D
higher-order representative. Это меняет критерийную интерпретацию, но не
закрывает окончательную physical criticality для задачи
\texttt{simple support / подвижный шарнир}.

\section{Неизвестные и mixed-weak структура}
\paragraph{Принятая рабочая структура.}
Сохраняемой рабочей базой ветви являются исправленная кинематика вместе с
исправленным окружным изгибным блоком, уже зафиксированным в основном
теоретическом файле.
Активные mixed-weak блоки неизвестных и результант имеют вид
\[
U = (u_s, u_n, v, \varphi, \psi),
\qquad
P = (T_s, T_\theta, S, Q_s, M_s, M_\theta, H, \chi).
\]
В текущей реализации первичный вектор коэффициентов задается как
\[
(u_s, u_n, v, \varphi, \psi, T_s, Q_s, M_s),
\]
тогда как $T_\theta$, $S$, $M_\theta$, $H$ и $\chi$ восстанавливаются
алгебраически из этих первичных полей и осесимметричного фона.

Центральной особенностью ветви является наличие двух независимых окружных
каналов,
\[
(v,S), \qquad (\psi,H,\chi),
\]
которые рассматриваются как подлинные части класса операторов, а не как
избыточные следствия более старой логики замыкания.
Pilot 02 локально замыкает это разделение на уровне текущих формул и
абстрактной логики-свидетеля.

Текущие базовые кинематические меры, сохраняемые в теоретическом файле, таковы:
\[
\varepsilon_s(U) = u_s' - \kappa_{s0}u_n,
\qquad
\varepsilon_\theta(U) = \frac{c_0u_s+s_0u_n}{x} + \frac{n}{x}v,
\]
\[
\gamma_{s\theta}(U) = v' - \frac{r_0'}{r_0}v - \frac{n}{x}u_s,
\qquad
g_n(U) = u_n' + \lambda_{s0}\varphi - \kappa_{s0}u_s,
\qquad
\kappa_s(U) = \varphi'.
\]
Здесь $c_0=\cos\varphi_0$, $s_0=\sin\varphi_0$,
$\lambda_{s0}=1+e_{s0}$, $\lambda_{\theta0}=r_0/x$,
а $\kappa_{s0}=\varphi_0'$ являются фоновыми величинами.

\section{Текущая система и уточненные формулы}
Активный mixed-weak оператор на уровне репозитория суммируется в виде
\[
A_n(X, \widehat X; q)
 = K_n(X, \widehat X) - G_{\mathrm{ps},n}(X, \widehat X; q)
   + B_{\mathrm{partial},n}(X, \widehat X) = 0,
\qquad X=(U,P).
\]
Это текущее рабочее утверждение об операторной форме.
Полное выведение каждого слагаемого на уровне статьи все еще остается
открытым, однако ветвь больше не описывается как единый скалярный потенциал
преднапряжения $G(U)$.

\subsection{Алгебраические mixed-weak реконструкции}
Текущая реализация использует следующие алгебраические реконструкции:
\[
r = c_0u_s+s_0u_n,
\qquad
S = \frac{v' - a_0v - (n/x)u_s}{2(1+\nu)},
\]
\[
\kappa_\theta^{\mathrm{new}}
 = \frac{c_0}{r_0}\varphi - \frac{s_0}{r_0^2}r + b_\theta\psi,
\qquad
M_\theta = \nu M_s + \frac{\kappa_\theta^{\mathrm{new}}}{\Lambda},
\]
\[
H = \frac{\psi' - a_0\psi - b_s\varphi}{C_{\mathrm{twist}}},
\qquad
\chi = \frac{b_\theta M_\theta - H' - 2a_0H}{\lambda_{\theta0}}.
\]
Эти соотношения лежат в основе текущего разделения каналов, проверенного в
pilot 02.

\subsection{Текущее замкнутое утверждение для блока преднапряжения/нагрузки}
Наиболее сильное из доступных сейчас на уровне репозитория замкнутое
утверждение для активного блока преднапряжения/нагрузки имеет вид
\[
G_{\mathrm{ps},n}^{\mathrm{repo}}(X,\widehat X;q)
:= \int_{x_0}^1
\bigl( \widehat T_s\, g_s^{\mathrm{repo}}(X;q)
     + \widehat Q_s\, g_n^{\mathrm{repo}}(X;q)
     + \widehat M_s\, g_m^{\mathrm{repo}}(X;q)
\bigr)\,dx,
\]
при этом общий знак фиксируется только через
\[
A_n = K_n - G_{\mathrm{ps},n} + B_{\mathrm{partial},n}.
\]
Текущие форсирующие члены на пробной стороне задаются так:
\[
r(X)=c_0u_s+s_0u_n,
\qquad
r_x(X)= -\kappa_{s0}s_0u_s + c_0u_s' + \kappa_{s0}c_0u_n + s_0u_n',
\]
\[
T_\theta(X) = \nu T_s + \frac{r(X)}{x} + \frac{n}{x}v,
\qquad
e_s^{\mathrm{code}}(X) = T_s - \nu T_\theta(X),
\]
\[
g_s^{\mathrm{repo}}(X;q)
 = -\frac{T_\theta^0}{r_0}r_x(X) - T_{sn}^0\varphi',
\]
\[
g_n^{\mathrm{repo}}(X;q)
 = T_s^0\varphi' + \frac{c_0}{x}T_\theta^0\varphi
   - \frac{q^0}{x}\bigl(r_0 e_s^{\mathrm{code}}(X) + \lambda_{s0}r(X)\bigr),
\]
\[
g_m^{\mathrm{repo}}(X;q) = \frac{M_\theta^0}{r_0}r_x(X).
\]
В текущей реализации $T_{sn}^0$ хранится как фоновая величина $Q_0$.
Это замкнутое утверждение теперь доступно на уровне репозитория, однако оно
все еще не является окончательной полной формулой уровня статьи для всего
$G_{\mathrm{ps}}$.

\paragraph{Статус.}
Pilots 06 и 06b локально уточняют этот блок.
Они показывают, что активный форсирующий блок билинеен по текущим смешанным
пробному и тестовому слотам и не сводится к скалярному замыканию только по $U$, при том
что полное выведение уровня статьи остается открытым.

\section{Граничные условия и сопряженные пары}
Текущие сопряженные пары на правой границе имеют вид
\[
(T_s,u_s), \qquad (Q_s,u_n), \qquad (S,v), \qquad (M_s,\varphi), \qquad (H,\psi).
\]
Для текущей mixed-weak рабочей постановки на границе существенные условия таковы:
\[
u_n(1)=0, \qquad \varphi(1)=0,
\]
при свободных вариациях на правой границе по $u_s(1)$, $v(1)$ и $\psi(1)$.
Отсюда следуют естественные условия
\[
T_s(1)=0, \qquad S(1)=0, \qquad H(1)=0.
\]

\paragraph{Статус.}
Pilot 01 доказывает это сокращение локально на уровне сопряженных граничных
пар с помощью CAS и Lean.
Это замкнутый локальный шаг, но еще не полное выведение всей слабой формы.

\section{Текущий критерий критичности}
Текущее утверждение о center-regular scaling имеет вид
\[
u_s,u_n,v = O(x^n),
\qquad
\varphi,\psi = O(x^{n-1}),
\qquad
T_s,S,T_\theta = O(x^{n-1}),
\]
\[
Q_s,M_s,M_\theta,H,\chi = O(x^{n-2}).
\]
В пределах текущей границы верификации физическое регулярное семейство в
центре рассматривается как двумерное.
Текущее построение реализует две регулярные в центре моды посредством наложения
\[
\frac{u_n}{x^n} + \frac{\lambda_c}{n}\frac{\varphi}{x^{n-1}} = 0,
\qquad
\frac{\psi}{x^{n-1}} - \lambda_c\frac{\varphi}{x^{n-1}} = 0,
\]
при нормировке одной моды, ведущей по $u_s$, и одной моды, ведущей по
$\varphi$.
После этого mixed-weak граничная матрица строится как
\[
B_{\mathrm{mix}} = B_{\mathrm{full}} V_{\mathrm{reg}},
\]
где $V_{\mathrm{reg}}$ строится из этих двух регулярных в центре мод, а не из
сырых суррогатных направлений ядра.
Текущий рабочий спектральный критерий имеет вид
\[
Однако theorem-facing интерпретация для текущего clean path уже не может
опираться на whole raw local regular family. После pilot 23 selected leading
trace замкнут только на selected family, и конечномерный reduced object следует
писать как
\[
L_{\mathrm{red},n}(q) = [A_{\mathrm{int},n}(q);B_{\mathrm{full},n}(q)]V_{\mathrm{adm},n}(q),
\]
а companion boundary-only objects --- как
\[
B_{\mathrm{red},n}(q)=B_{\mathrm{full},n}(q)V_{\mathrm{adm},n}(q),
\qquad
B_{\mathrm{mix},n}(q)=B_{\mathrm{red},n}(q)G_{\mathrm{amp},n}(q).
\]
Здесь $A_{\mathrm{ls}}=\operatorname{im}(V_{\mathrm{adm}})=\operatorname{im}(M_{\mathrm{amp}})$
следует читать как current global weak/KKT-selected family. Локальный
theorem-facing результат pilot 23 на checked local boundary замыкается не как
canonical 2D higher-order representative, а как quotient object.

Поэтому raw working spectral diagnostic по-прежнему записывается как
\[
\sigma_{\min}(B_{\mathrm{mix}}(q)) = 0,
\]
но его нужно читать только как exploratory diagnostic, а не как установленную
эквивалентность nontrivial-kernel question для $L_{\mathrm{red}}$.

\paragraph{Вывод.}
Pilots 03--05 и clean theorem-facing линия pilot 23 вместе требуют более
осторожного criterion-level reading: current selected reduced family и
диагностики $B_{\mathrm{mix}}$ / $\sigma_{\min}(B_{\mathrm{mix}})$ остаются live
на clean path, но criterion-level equivalence между raw boundary-only reading и
полным reduced operator не доказана.
\section{Главные выводы}
Итоговая рабочая картина для текущего этапа такова:
\begin{enumerate}[leftmargin=2em]
    \item Активным путём для задачи остаётся clean full-state path для
    \texttt{simple support / подвижный шарнир}.
    \item Текущая mixed-weak реализация использует честный осесимметрический фон
    и самостоятельный critical-search слой без возврата к old hybrid $F_{\min}$ line.
    \item Current selected reduced family на live clean path следует читать как
    global weak/KKT-selected family $A_{\mathrm{ls}}$.
    \item Theorem-facing reduced operator остаётся $L_{\mathrm{red}}$, а
    boundary-only companion objects --- $B_{\mathrm{red}}$ и $B_{\mathrm{mix}}$.
    \item $\sigma_{\min}(B_{\mathrm{mix}})$ и light criterion pilots надо
    трактовать как exploratory diagnostics, а не как уже закрытую замену
    nontrivial-kernel question для $L_{\mathrm{red}}$.
    \item Current candidate load / mode reading остаётся exploratory, пока не
    построен criterion bridge к final physical interpretation.
\end{enumerate}

\section{Что уже проверено и что ещё открыто}
\subsection{Что уже проверено}
На текущем этапе уже проверены следующие блоки, достаточные для текущей
criterion-facing синхронизации:
\begin{itemize}[leftmargin=2em]
    \item \textbf{Независимость граничных каналов и базовые пары сопряжения}
    проверены в pilot 01.
    \item \textbf{Декомпозиция $(v,S)$ и $(\psi,H,\chi)$} ведёт к текущим
    обозначениям $S$, $H$ и $\chi$ на active mixed-weak path через pilot 02.
    \item \textbf{KKT-selected reading of the reduced family.}
    Clean theorem-facing линия pilot 23 зафиксировала, что $A_{\mathrm{ls}}$
    следует читать как global weak/KKT-selected family, а не как whole raw local
    regular family.
    \item \textbf{Selected leading trace plane.}
    На текущем checked leading-center level selected trace exactly equals
    $J_0(A_{\mathrm{ls}})=\operatorname{im}(D_{\mathrm{amp}})$.
    \item \textbf{Higher-order local stopping point.}
    На текущей checked local boundary higher-order local selected object
    canonically closes only as quotient
    $\operatorname{im}(D_{\mathrm{rich},\eta}^{\mathrm{corr}}) / \operatorname{span}(g_{\mathrm{mem}})$.
    \item \textbf{Boundary-only criterion diagnostics.}
    $B_{\mathrm{mix}}$ и $\sigma_{\min}(B_{\mathrm{mix}})$ остаются live,
    computable и operationally useful как exploratory diagnostics на clean path,
    но не как closed final physical criterion.
\end{itemize}

\subsection{Что ещё открыто}
Остаются следующие центральные открытые вопросы:
\begin{itemize}[leftmargin=2em]
    \item полное theorem-facing замыкание mixed-weak системы на уровне всей задачи,
    включая аккуратную историю для блока $G_{\mathrm{ps}}$;
    \item окончательная формулировка критерия на уровне всей системы, а не только
    на уровне boundary-only diagnostics;
    \item criterion-level bridge между local quotient result и global reduced
    criterion: как именно nontrivial-kernel question для
    $L_{\mathrm{red}}$ должно читаться рядом с boundary-only objects
    $B_{\mathrm{red}}$ и $B_{\mathrm{mix}}$;
    \item физическая интерпретация current candidate loads / modes для полной задачи;
    \item итоговый theorem-facing bridge между current quotient-local result и
    final physical criticality для clean simple support / подвижный шарнир постановки.
\end{itemize}
В текущей clean competition memory exploratory остаётся следующая картина: mode
$n=6$ поддерживается как supported interior candidate около
$17.6\,\mathrm{MPa}$, $n=8$ остаётся unstable rival около
$17.8\,\mathrm{MPa}$, $n=7$ остаётся raw reserve dip, а $n=4$ --- control mode.
Ни одно из этих чисел пока не является final physical critical-load claim.

\section{Заключение}
Текущая mixed-weak линия теперь должна читаться на двух уровнях
одновременно. Clean full \texttt{simple support / подвижный шарнир} path даёт
честный background, theorem-facing reduced operator $L_{\mathrm{red}}$,
boundary-only companion objects $B_{\mathrm{red}}$ / $B_{\mathrm{mix}}$ и
локальный pilot-23 result, который на checked local boundary закрывается как
Outcome B: правильный theorem-facing selected object там является quotient, а не
canonical 2D higher-order representative.

Это накладывает criterion-level caution. Raw
$\sigma_{\min}(B_{\mathrm{mix}})$ reading остаётся полезным exploratory
diagnostic для clean candidate competition, но не может уже сейчас считаться
полным criterion for physical criticality. Поэтому ближайший рабочий шаг должен
состоять не в дальнейшем углублении той же checked local branch, а в synthesis /
bridge between the local quotient result and the global reduced criterion story.

$V_{\mathrm{reg}}$ & двухколоночная матрица регулярных в центре мод \\
$B_{\mathrm{mix}}$ & mixed-weak граничная матрица \\
